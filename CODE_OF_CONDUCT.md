# Code of conduct

Egressa adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every space the project runs: issues, pull requests, discussions and
reviews.

In short: be respectful and assume good faith; criticise ideas, not people; no harassment,
personal attacks or publishing someone's private information. The knowledge base makes factual
statements about named companies, so a disagreement about an entry is settled by sources under
[kb/KB_POLICY.md](kb/KB_POLICY.md), not by argument.

## Reporting

Report conduct concerns privately to contact@jatinbharati.com, not in a public issue or comment.
Reports are handled in confidence, and the enforcement guidelines of the Contributor Covenant 2.1
apply.
